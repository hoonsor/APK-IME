# zhuyin-voice-ime

個人自用 Android 輸入法：**超注音式簡拼注音** + **Typeless 等級 AI 語音輸入**，兩者共用同一份個人詞庫——
用注音建立的慣用詞，語音輸入也能正確辨識。

## 文件導覽

| 文件 | 內容 |
|------|------|
| `docs/FEATURES.md` | 完整功能清單、優先順序、負責模組 |
| `docs/ARCHITECTURE.md` | 模組結構、介面、流程、合併點 |
| `docs/CONVENTIONS.md` | 平行開發規則、分支、契約變更流程、機密處理 |
| `docs/ZHUYIN_HANDOFF.md` | 對話 A（注音鍵盤）的開工說明 |
| `docs/VOICE_HANDOFF.md` | 對話 B（語音模組）的開工說明 |
| `docs/REQUESTS.md` | 雙方提出的契約變更需求 |

## 狀態

Step 0：骨架與契約完成，尚未有可執行功能。第一次用 Android Studio 開啟時會自動下載 Gradle 並同步。
