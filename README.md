# 倬注音（APK-IME）

> 個人自用的 Android 輸入法：超注音式的簡拼注音鍵盤，加上 Typeless 等級的 AI 語音輸入與 AI 改寫，兩者共用同一份個人詞庫。
> 目前版本：**v0.7.0**（開發中，個人實機測試階段）｜給 AI 接手的說明在 `AGENTS.md`。

## 📖 專案簡介 (Overview)

倬注音是一套裝在 Android 手機上的中文輸入法。打字的部分沿用超注音的操作習慣：大千注音鍵盤、簡拼（只打聲母就能出詞，例如「ㄋㄏ」出「你好」）、逐字選字自動建立自建詞、扇形切換符號與數字、編輯面板與剪貼簿歷史，盡量讓用慣超注音的人不用重新學。

說話的部分則補上超注音沒有的 AI 能力：按下麥克風說話，語音先由雲端模型轉成文字，再由大型語言模型去掉贅字、處理口誤改口、補上標點，轉成台灣繁體用語後直接送進輸入框。除了聽寫，也能用說的修改選取的文字、直接翻譯；在編輯面板還能一鍵「潤飾全文」、「AI 寫作」、「翻英全文」，不滿意可以還原原文。

開發的出發點是：Typeless 的潤飾效果很好，但自訂的慣用詞常常辨識錯，而超注音的語音功能又沒有潤飾與改寫。倬注音把注音打出來的自建詞、英文詞自動注入語音辨識與 AI 潤飾的提示裡，常用的人名、專有名詞、技術名詞用說的也能正確輸出。

這個專案為個人使用而設計，以穩定為第一優先：鍵盤主體只用 Android 框架、不依賴第三方 UI 函式庫；API key 以 Android Keystore 加密只存在手機；AI 失敗時自動改用備援模型，額度用完時會提醒並改輸出原文，不會讓打字卡住。

## 1. 安裝

1. 電腦裝 Android Studio，專案放在**英文路徑**（例如 D 槽的 dev 資料夾底下，資料夾名稱用英文）。
2. 第一次開啟：Settings → Build, Execution, Deployment → Build Tools → Gradle → **Gradle JDK 選 jbr-21**（Gradle 8.9 不支援 Java 25）。
3. 手機開啟「開發人員選項 → USB 偵錯」，接上電腦，按 ▶ **Run**。
4. 之後更新：改用「7. 手機端更新」的 App 內更新或 Obtainium，不用再接線。覆蓋安裝會保留字典與設定；**不要先解除安裝**（會清掉字典與 API key），真的要解除安裝，先「匯出字典」。

## 2. 首次設定（ColorOS）

> ColorOS 各版本的選單名稱可能略有不同，找不到時用設定頁上方的搜尋輸入「鍵盤」。

1. 開啟「倬注音」App → 按 **開啟系統輸入法設定**。
   - ColorOS 大多在：設定 → 其他設定（或「系統設定」）→ 鍵盤與輸入法 → 管理鍵盤，把「倬注音」打開。出現「可能收集你輸入的文字」的系統警告是所有第三方輸入法都會有的，按確定。
2. 回到 App → 按 **切換輸入法** → 選「倬注音」。（也可以在任何輸入框，從通知列或導覽列的鍵盤圖示切換。）
3. 在 App 的「試打」框打幾個字確認可以用。
4. 要用語音或 AI：鍵盤 ⚙ → **AI模型設定**
   - 「1. API Key」貼上 Groq（必要）、MiniMax（文字 AI 用，選填）的 key → 儲存 → **測試連線**。
   - 「2. 模型」每一欄按 **測試**，顯示「可以使用」就好。建議：語音轉文字 Groq `whisper-large-v3`；語音潤飾 Groq `openai/gpt-oss-120b`；文字 AI 主要 Groq、備援 MiniMax-M3。
   - 「3. 語音輸入」按 **授權麥克風**。
5. 如果 Groq 測試出現「HTTP 403 … blocked at the project level」：到 console.groq.com → Settings → Projects → 該 project 的模型權限，把模型改成允許；或換成其他 Groq 模型。

## 3. 功能怎麼用

### 3.1 注音打字
- **簡拼**：每個字只打開頭注音即可，例如 ㄋㄏ → 你好、ㄆㄥㄢ → 平安；加聲調可以縮小範圍（ㄆˊㄧ → 朋友），空白鍵 = 一聲。
- **候選列**：▼ 展開全部候選、左右滑看更多、› 翻頁；第一個候選反白。
- **自建詞**：逐字選字會自動成詞（ㄋㄧㄏㄠ 先選「妳」再選「好」→ 之後直接出「妳好」）；候選字右上角 ᵁ = 自建詞。
- **刪除自建詞**：長按候選詞 0.8 秒 → 候選列出現「刪除「詞」／取消」。內建詞無法刪。
- **聯想詞**：選字後候選列出現接續詞；想回到工具列，在候選列**上下滑**一下。
- **四符號鍵**（空白鍵左右各一顆）：點一下＝鍵面左下（粉紅色）的符號；按住往 ↖ ↗ ↘ 滑放開＝該角的符號。
  - 注音左鍵：點「，」、↖「？」、↗「、」、↘「！」；注音右鍵：點「。」、↖「&」、↗「●」、↘「（」（會自動補「）」）。

### 3.2 英文、符號、數字
- **英文**：按「ABC」；⇧ 點一下下一字大寫、快速點兩下大寫鎖定（鍵下黃線）、再點解除。
- **英文四符號鍵**：左鍵點「@」、↖「,」、↗「-」、↘「_」；右鍵點「.com」、↖「.」、↗「~」、↘「;」。打 `abc` → 點左鍵 → `gmail` → 點右鍵，就是 `abc@gmail.com`。
- **扇子鍵**：按住往方向滑放開，或點一下停留再點：**半**（半形符號）、**全**（全形符號）、**數**（撥號式數字鍵盤）、**剪**（剪貼簿）。
- **符號鍵盤**：右欄 ▲ ▼ 翻頁、頁碼、📌 鎖定（鎖定後連續打不會跳回）。半形第一頁依鍵盤數字列順序：! @ # $ % ^ & * ( ) - _ = + 與常用標點。
- **成對符號**：打「（」「「」「【」等前符號會自動補後符號、游標放中間；再打後符號會跳過，不會多一個。
- **英文詞加入字典**：連續打英文／數字／符號（例如 `abc@gmail.com`）時，候選列出現「abc@gmail.com ＋」，點一下加入；之後打前幾個字母就會出現。

### 3.3 工具列
⚙ 齒輪選單（參數設定／高度調整／常用短語／AI模型設定）｜🎤 語音｜繁／簡 切換輸出｜← → 移動游標｜☰ 編輯面板｜⌨ 收鍵盤｜📋 剪貼簿（設定中開啟）

### 3.4 編輯面板（☰）
- **沒選取**：開選、行首、上移、行尾、**潤飾全文**／剪下、左移、全選、右移、**AI 寫作**／貼上、後刪、下移、前刪、**翻英全文**。
- **有選取**：複製、…、**潤飾**／…、停選、…、**納入字典**／…、**翻英**。
- 長按「貼上」開啟剪貼簿。
- **AI 寫作**：先在輸入框打一段要求（例如「跟客戶說交期延後一天，語氣客氣」），再按 AI 寫作，整段會換成完整文字。
- AI 完成後候選列出現「↶ 還原原文」。處理中可按「取消」。

### 3.5 語音輸入（🎤）
- 模式：**聽寫**（潤飾後輸出）、**修改選取**（先選取文字，再用說的下指令）、**翻譯**（說中文、輸出目標語言）。
- 按「按我開始說」，說完按「說完了，按我送出」；設定可改成按住說話、開面板自動錄音。
- 上方「取消」可中止；完成後「還原原文」可換回未潤飾的逐字稿。
- 第一排快速標點「， ？ 、 ！ ␣ 。 ← →」讓你說完立刻補標點；「↩」回注音鍵盤。

### 3.6 剪貼簿
- 輸入法開著時會記錄你複製的文字（只存在手機；密碼管理器等標記為敏感的不記錄；最多 100 筆，釘選不會被清除）。
- 開啟：扇子「剪」、編輯面板長按「貼上」、工具列 📋。每筆可 📌 釘選、✕ 刪除，點一下貼上。
- 🔍 搜尋：用注音鍵盤打關鍵字，上方出現結果，點選即貼；Enter 貼第一筆。
- 剛複製的內容 2 分鐘內會在候選列顯示「📋 …」一點即貼。

### 3.7 常用短語
⚙ → 常用短語 → 點一下送出；「管理」到設定頁新增、編輯、刪除（可多行）。

### 3.8 AI 額度與備援
- 每個用途都有主要與備援模型；每家供應商可設定「備用 API key」（**只放同帳號其他專案或付費 key**，用多個免費帳號繞額度違反 Groq 條款）。
- 全部額度用完時，鍵盤會跳出「⚠ AI 免費額度已達上限」，之後語音潤飾與文字 AI 會**直接輸出原文**；同一則提醒 30 分鐘內只跳一次。

## 4. 語音指令範例

**修改選取**（先選取文字，再說）：
- 「改得正式一點」「縮短成一句」「改成條列式」「翻成英文」「語氣客氣一點」

**聽寫**（直接說，潤飾會自動處理）：
- 「明天下午三點開會，不對，改四點」→ 明天下午四點開會。
- 「嗯那個我想問一下報價單寄了嗎」→ 我想問一下，報價單寄了嗎？

**未來 AI 大腦可用的說法（規劃中，尚未實作，見 `docs/AGENT_API.md`）**：
- 「把『拉斐爾』加到字典」「我存了哪些英文詞」「剪貼簿最近複製了什麼」
- 「語音潤飾改用 Groq 的 gpt-oss-120b」「切換成簡體輸出」「備份我的字典」

## 5. 備份與還原（設定頁 → 4. 使用者字典）

- **匯出字典並分享**：產生 `倬注音字典_日期時間.csv`，可存到 Google Drive、Dropbox，或用 Email、LINE 傳。
- **匯出字典存到手機檔案**：存到你選的資料夾。
- **匯入字典**：可直接從 Google Drive／Dropbox 選檔。
  - **合併**：只新增或更新，手機原有的詞都保留。
  - **取代**：以檔案為準，檔案裡刪掉的詞手機也刪掉（會再確認一次）。
  - 匯入前會自動保留一份，按「**復原上次匯入前的字典**」可還原。
- **在電腦編輯**：用 Excel 或 Google 試算表開啟。欄位：類型（中文詞／英文詞／常用短語）、內容、注音（中文詞可留空，匯入時自動判斷）、使用次數。Excel 存檔選「CSV UTF-8（逗號分隔）」；看到 `="0912345678"` 是正常的（防止 Excel 吃掉開頭 0）。最後的「學習紀錄」是選字次數，不用編輯。
- 舊版「備份字典」的 .tsv 檔也能用匯入還原。
- **API key 不會被匯出**；換手機或重裝後要重新貼上。

| 問題 | 解法 |

| Android Studio 拉取失敗「has no tracked branch」 | 本機資料夾沒接 GitHub；請 AI 直接把檔案寫進資料夾，或重新 clone 一份到英文路徑的新資料夾（例如 `APK-IME`） |

## 7. 手機端更新（不用接線）

正式版由 GitHub Actions 編譯、用共用金鑰 `hoonsor-release.jks` 簽章，發布在 [Releases](https://github.com/hoonsor/APK-IME/releases)。手機有兩種更新方式，擇一或並用：

**App 內更新（建議）**
- 每天第一次打開倬注音的設定頁時，在背景檢查一次；有新版會跳出版本號與更新說明，可選「下載並更新」「稍後」或「略過此版」。
- 設定頁最下方「6. App 更新」可隨時按「檢查更新」。
- 第一次更新時會引導你到「安裝不明應用程式」允許倬注音，按返回鍵回到設定頁後自動開始下載。
- 鍵盤本身不會連網檢查更新，打字完全不受影響；沒網路時安靜略過。
- 更新完成後字典、設定、API key 都保留，下次叫出鍵盤就是新版（若鍵盤暫時沒出現，切換一次輸入法即可）。

**Obtainium 設定**
1. 在手機安裝 [Obtainium](https://github.com/ImranR98/Obtainium/releases)。
2. 「Add App」→ App Source URL 填 `https://github.com/hoonsor/APK-IME`。
3. 保持「Include prereleases」關閉（`latest` 是每次推送 main 自動編譯的測試版，不要追它）。
4. 若同一個 Release 未來有多個 APK，在「Filter APKs by Regular Expression」填 `HoonsorIME-v.*\.apk`。
5. 新增後 Obtainium 會定期檢查，有新版時通知並一鍵安裝。

**第一次切換到正式簽章版（只需一次）**：手機上現在是 Android Studio 直接安裝的 debug 版，簽章不同，系統不允許覆蓋安裝。請先在設定頁「4. 使用者字典」**匯出字典並分享**到雲端 → 記下各 API key（解除安裝會清掉，也不會被匯出）→ 解除安裝 → 從 Releases 安裝正式版 → 重新啟用輸入法、匯入字典（選「取代」）、重新貼上 API key。之後就都能直接更新。

## 8. 如何發新版

1. 修改 `app/build.gradle.kts` 的 `versionCode`（加 1）與 `versionName`（例如 `0.7.1`）。
2. 在 `PROJECT_STATUS.md` 的「版本歷程」表格最上面新增一列 `| v0.7.1 | 日期 | Commit | 變更內容 | 為什麼 |`；「變更內容」與「為什麼」會自動成為 Release 的更新說明（也就是 App 內更新對話框顯示的內容）。
3. 提交並推送 main，接著推送同名 tag：

   ```bash
   git tag v0.7.1
   git push origin main v0.7.1
   ```

4. GitHub Actions 會跑單元測試（注音引擎、語音文字規則、更新邏輯）、編譯 `HoonsorIME-v0.7.1.apk` 並建立正式 Release。tag 與 `versionName` 不一致時 CI 會直接失敗，避免 App 一直以為有新版。

其他說明：
- 每次推送 main 都會更新名為 `latest` 的預先發行版（`HoonsorIME-latest.apk`），給想搶先測試時手動下載；App 內更新與 Obtainium 預設都不會把它當成新版。
- 簽章 Secrets（`SIGNING_KEYSTORE_B64`、`SIGNING_STORE_PASSWORD`、`SIGNING_KEY_ALIAS`、`SIGNING_KEY_PASSWORD`）已由倬寫入 repo。沒有 Secrets 時 CI 會用 debug 簽章並顯示警告，這種 APK 無法覆蓋安裝，不要拿來發正式版。
- 本機 `./gradlew :app:assembleRelease` 沒有設定 `SIGNING_KEYSTORE_PATH` 時會用 debug 簽章，只能自己測試。

## ✨ 核心功能 (Key Features)
- **簡拼注音**：聲母簡拼、組字框分段顯示、候選列（▼ 展開、左右滑動）、聯想詞；內建約 17 萬詞（McBopomofo 詞庫）。
- **個人字典**：逐字選字自動成詞、英文／符號詞一鍵「＋」加入字典、選取文字「納入字典」自動反查注音；設定頁可檢視、搜尋、編輯；可匯出 CSV 到電腦用 Excel／Google 試算表編輯後再匯入，或分享到 Google Drive、Dropbox 備份。
- **AI 語音輸入**：聽寫／修改選取／翻譯三種模式，點按或按住說話，快速標點列；靜音偵測、幻覺過濾、簡轉繁（OpenCC s2tw）。
- **AI 改寫**：編輯面板的潤飾（選取／全文）、AI 寫作、翻英，完成後可「還原原文」。
- **AI 模型設定**：Groq／MiniMax／OpenAI，語音轉文字、語音潤飾、文字 AI 各自選模型並有備援；可設定備用 API key；額度用完自動提醒並改用原文輸出。
- **符號與數字**：扇形切換「半／全／數／剪」，符號鍵盤可翻頁（箭頭、核取方塊、希臘字母、數學、框線等），撥號盤式數字鍵盤，成對符號自動補齊並把游標放中間。
- **剪貼簿**：輸入法使用中自動記錄文字（敏感內容不記錄、只存本機），可釘選、搜尋、一點即貼；剛複製的內容在候選列直接貼上。
- **其他**：繁／簡輸出切換、常用短語、編輯面板（開選、全選、游標移動、前後刪）、大寫鎖定、鍵盤高度調整、密碼欄位自動停用 AI 與學習。

## 🛠 技術棧 (Tech Stack)
- **語言 / 平台**：Kotlin 2.1、Android（minSdk 29、compileSdk 36），InputMethodService
- **UI**：Android 框架元件與自繪 View（不使用 Compose / AndroidX，保持輸入法輕量穩定）
- **AI 串接**：OpenAI 相容 API（Groq、MiniMax、OpenAI），HttpURLConnection，無第三方 HTTP 函式庫
- **資料**：詞庫 TSV 資產、使用者詞庫文字檔（原子寫入）、SharedPreferences、Android Keystore（AES-GCM）
- **建置工具**：Gradle 8.9、Android Gradle Plugin 8.7.3、KSP

## 🚀 快速開始 (Quick Start)

```bash
git clone https://github.com/hoonsor/APK-IME.git
# 用 Android Studio 開啟資料夾（英文路徑），Gradle JDK 選 jbr-21，等待 Sync 完成
./gradlew :engine:zhuyin:test     # （可選）注音引擎測試
./gradlew :app:installDebug       # 或 Android Studio ▶ Run
```

## 📁 專案結構 (Project Structure)
```text
app/                 # 輸入法主體：鍵盤、候選列、面板、剪貼簿、設定頁、AI 模型設定、字典匯出入

tools/build_dict.py  # 由 McBopomofo 資料產生 zhuyin_dict.tsv
docs/                # 功能清單、設計、語音 API、歷史文件
```
