## 2. 尺寸

| 項目 | 值 |
|---|---|
| 鍵盤（面板區）高度 | 預設 230dp，可調 180～400dp（齒輪 → 高度調整） |
| 頂列（工具列／候選列） | 52dp |
| 組字框區 | 32dp，透明浮在 App 上方 |
| 候選字 | 28sp；英文／數字／符號為主的候選 19sp；左右留白 6dp；項目高 48dp |
| 展開候選格 | 字 27dp、格高 52dp |
| 工具列圖示 | 比初版放大約 30%（按鈕數不變） |

| 齒輪選單 | 寬約 96%、高 136dp，4 欄 |

## 3. 元件規則

- **頂列單一列**：工具列（⚙ 🎤 繁 ← → ☰ ⌨，可選 📋）與候選列共用同一列；有候選、聯想、英文詞、提示時顯示候選列。候選列上下滑回工具列，左右滑捲動。
- **候選列**：最左 ▼ 展開、中間可左右滑、最右 › 翻頁；第一個候選反白；U／C 上標表示自建詞／聯絡人；長按 0.8 秒刪自建詞（候選列確認）。
- **扇子**：單圈，項目 半／全／數／剪，放射線連到扇子鍵；依方向選取。
- **符號鍵盤**：左 7×4 符號，右欄 ▲／▼／頁碼／📌；最下排 返回（ABC 或 ㄅㄆㄇ）、空白、⌫、↵。
- **數字鍵盤**：撥號盤 1–9、*、0、#，側欄 - . ⌫ ↵，底排 返回 , 空白 + /。
- **編輯面板**：5 欄 × 3 列，第 5 欄是 AI 欄（AI_BG 底、ACCENT 字）；依有無選取切換（見 `docs/FEATURES.md` K10）。
- **語音面板**：上方模式列（聽寫／修改選取／翻譯，右側 取消／還原原文）→ 波形 30dp → 狀態文字 → 快速標點列「， ？ 、 ！ ␣ 。 ← →」→ 底排「↩」「按我開始說」（大鍵）「⌫」「↵」。
- **提示**：放候選列（ACCENT 字）3 秒；重要提醒（額度用完）用鍵盤內覆蓋視窗＋「知道了」。
- **設定頁**：框架元件、NoActionBar、自行套系統列 inset。
