# 功能清單（FEATURES）

> 來源：超注音 Google Play 說明、官網更新日誌（superkbd.com，至 Android v3.5.4 / 2026-10-06）、
> iOS App Store 說明、倬提供的設定畫面與鍵盤截圖（2026-10-08）。
> 目標：保留超注音全部實用功能，並把語音輸入升級到 Typeless 等級。
>
> 優先順序：**P0** = 日常打字不可或缺（MVP）｜**P1** = 常用、第二階段｜**P2** = 錦上添花
> 負責：**A** = 對話 A（注音鍵盤 / 主程式）｜**B** = 對話 B（語音模組）｜**共** = 共用層，改動需雙方同步
> 標記 ❓ = 行為細節需在實機上對照超注音確認

## 1. 注音輸入引擎（`:engine:zhuyin`，A）

| # | 功能 | 說明 | 優先 |
|---|------|------|------|

| Z4 | 候選詞排序與使用頻率學習 | 選過的詞往前排 | P0 |
| Z5 | 自建詞彙 | 輸入 ㄒㄧㄠㄗㄋㄢ 後依序選「小」「資」「男」即建詞 | P0 |
| Z6 | 刪除使用者詞彙 | 長按候選詞或按住往下滑 → 確認刪除 | P0 |

## 5. 語音輸入（`:feature:voice`，B）— Typeless 等級

超注音現況（v3.5.3）已支援：OpenAI gpt-4o-mini-transcribe / gpt-4o-transcribe / gpt-transcribe、
「開始/停止」與「按住即說」兩種錄音方式、關鍵詞、風格範例與情境提示、錄音壓縮。
以下是本專案要做到的範圍：

| # | 功能 | 說明 | 優先 |
|---|------|------|------|
| V1 | 錄音 → STT | 雲端 STT（可選模型），錄音方式：點按開始/停止、按住即說 | P0 |
| V2 | **AI 潤飾** | 去贅字（嗯、那個）、處理口誤自我修正（「明天，不對，後天」→ 後天）、補標點、條列化、繁體台灣用語 | P0 |
| V3 | 個人字典注入 | 從 D6 讀取詞彙 → STT prompt / 關鍵詞 + LLM 校正 | P0 |
| V4 | **說話修改（Speak to Edit）** | 選取文字後說指令（「改得正式一點」「翻成英文」「縮短」）→ 取代選取內容 | P1 |
| V5 | 語音翻譯 | 說中文直接輸出指定語言 | P1 |
| V6 | 依 App 調整語氣 | 依目前 App（LINE / Gmail / Slack…）套用不同風格提示 | P1 |
| V7 | 取消 / 重試 / 原文還原 | 隨時取消；結果不滿意可一鍵還原為未潤飾逐字稿 | P0 |
| V8 | 語音面板 UI | 錄音波形、計時、狀態（錄音/轉錄/潤飾）、取消鍵 | P0 |
| V9 | 歷史紀錄 | 最近 N 筆結果可重新插入（本機保存） | P2 |
| V10 | 備援 | 主要 STT/LLM 失敗時自動改用備援模型；離線時明確提示 | P1 |
| V11 | 中英混說 | 中英夾雜正確輸出（英文術語保留英文） | P0 |
